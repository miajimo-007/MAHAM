DARRIK - read me first
=============================================================

WHAT'S IN THIS FOLDER
  DARRIK.html                 the app - one file, nothing to install
  DARRIK Data\         EVERYONE'S SAVED WORK - never delete, move or rename it
     users\                   one file per person, created when they first save
     Import\                  optional place for the old Excel sheets
     Backups\                 automatic daily copies of everyone's data (last 30 days)

SETUP (once)
1. Right-click the zip > "Extract All...".
2. Put the whole "DARRIK" folder on the team's shared drive.
3. Everyone needs modify (read + write) permission on that folder.

OPENING THE APP
Recommended: copy "DARRIK.html" to your Desktop and open it from there in Edge or Chrome.
1. Click "Choose folder..." and select the "DARRIK" folder (or the folder you already use) on the SHARED drive.
2. Allow "Edit files" (choose "Allow on every visit" if offered).
3. Pick your name, then set a PIN (menu on your name, bottom-left > Set my PIN).
You can also open the file directly from the shared drive through a mapped drive letter
(e.g. S:\...). Opening it from a network address (\\server\...) is usually blocked by Edge.

=============================================================
UPDATING TO A NEW VERSION
=============================================================
When a new version is put in the shared folder, the app shows a yellow bar:
"A new version of the app is available". Then:
  1. Press "Save" (top right) and close the app window.
  3. Copy the NEW "DARRIK.html" from the shared folder to the same place.
  4. Open it. You may be asked once to choose the folder / allow editing again.
Your work is safe: it is saved in "DARRIK Data" on the shared drive, not in the
.html file. Never delete the "DARRIK Data" folder.
(Administrator: to publish an update, replace "DARRIK.html" in the shared folder.
=============================================================

DAILY USE
- Saving is automatic; "Save" and "Refresh" are top right. Teammates' changes appear
  within about 20 seconds.
- ManageEngine: IT Help Desk > Import > choose the daily report (managers and team leaders).
- Requests (vacation, permission, any approval): menu > Requests.

ROLES (set by the super admin only, in Admin)
- Super admin: everything, including Admin, Settings, System Check and Import Old Data.
- AED: over every department and director (add the person in Admin > People with the role AED).
- Director: runs a department (e.g. IT) and its teams; assigns work and projects, sees the tasks they gave;
  final approvals. Departments are set in Admin > Teams & departments > Departments.
- Manager: runs the team, approves requests and quick wins, forwards director tasks.
- Team Leader: analyst work + ManageEngine import + team attendance + can lead projects.
- Analyst: own work, team dashboards, projects they are added to.
Permissions and access to each function can be changed per person by the super admin.
When a manager is on leave, the super admin can let someone act for them (Admin > Manager leave).
Admin > Home shows what needs attention; click a name for the person's card (offboard, view as).

BACKUP: the app saves a daily backup in "DARRIK Data\Backups" (restore: Admin > System Check).
For extra safety, now and then copy one backup somewhere else. Nothing is sent to the internet.
